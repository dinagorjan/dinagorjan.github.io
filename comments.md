# Palette Feedback

## Dusty warm neutrals — Score: 4/10

```css
--p1: #F5F0E8;   /* lightest  · page background          */
--p2: #EDD9C3;   /* soft      · highlights, text on dark */
--p3: #D4C5A9;   /* light mid · RSVP band start          */
--p4: #9B8B6E;   /* medium    · botanicals, icons        */
--p5: #4A3728;   /* darkest   · text, dark bands, CTAs   */
```

- The colors are too warm.
- The brown over "Counting down…" I don't like at all.
- The gradient over "RSVP" is too warm.
- I prefer more fresh colors.
